Install

Package Version Runtime (from the package manifest) Install
TypeScript SDK on npm 8.0.1 Node.js 18 or later, ES modules only npm install agent-passport-system@8.0.1
Python SDK on PyPI 4.3.0 Python 3.10 or later pip install agent-passport-system==4.3.0
Rust SDK on crates.io 0.3.0 No minimum compiler version is declared cargo add agent-passport-system@0.3.0
Go SDK on pkg.go.dev v0.7.0 go 1.22 in go.mod go get github.com/aeoess/agent-passport-go@v0.7.0
MCP server on npm 8.1.0 Node.js 20 or later npm install agent-passport-system-mcp@8.1.0

The four SDKs do different jobs. TypeScript and Python issue and verify the current AuthorityDelegationV1 record and its revocation record. The Rust crate only verifies, it creates no artifacts. The Go module signs and verifies its own chain shape. Check that the SDK you pick can produce or verify the artifact your peer sends before you build on it. Languages and artifacts has the table by artifact and operation.

TypeScript

Section titled “TypeScript”

The package is ES modules only. Your project needs "type": "module" in its package.json, or .mjs files. A CommonJS require('agent-passport-system') fails with ERR_PACKAGE_PATH_NOT_EXPORTED.

Package name and binary name

Section titled “Package name and binary name”

The npm package is agent-passport-system. The command line tool it installs is called agent-passport. Inside a project that has the package installed, npx agent-passport <command> runs it. In a directory without the package, npx agent-passport asks npm for a different package named agent-passport. Name the package explicitly instead:

Key pairs from generate_key_pair() use the keys publicKey and privateKey. The current authority record lives in agent_passport.v2.authority_delegation. The older create_delegation and verify_delegation produce the pre-draft compatibility format. This recipe issues a grant, verifies it with an explicit clock, key resolver, root trust policy and revocation resolver, then revokes it:

The revocation store here lives in process memory. A store that has never tracked a delegation answers unknown, and the verifier then returns indeterminate, never valid.

More modules are described in the Python SDK README. If its quick start still calls create_passport(agent_id=..., public_key=...), that example predates 4.3.0 and fails on it with KeyError: 'public_key'. Use the recipe above.

MCP server

Section titled “MCP server”

The local server runs over stdio on your machine:

setup writes an agent-passport entry into the Claude Desktop and Cursor configuration files in your home directory. Restart the client afterwards. See MCP server for manual configuration and for what the server reads, writes and contacts.

Hosted endpoint

Section titled “Hosted endpoint”

setup --remote writes the hosted endpoint https://mcp.aeoess.com/sse into the client configuration instead. The remote server README at commit b0cfb7f says the hosted endpoint is temporarily restricted and anonymous connections return HTTP 401, while self-hosting is unaffected. Use the local server.
