Each link below is followed by a line taken from the linked page or repository.

- [Agent Governance Vocabulary](https://github.com/aeoess/agent-governance-vocabulary): Agent Governance Vocabulary is a common reference for agent-governance systems.
- [Agent Authority Conformance](https://github.com/Agent-Authority-Conformance): an LF Decentralized Trust lab. Its Agent Passport System corpus holds byte-level test vectors, verifier adapters and reproducible run reports for identity, delegated authority and signed decision receipts.
- [Individual Internet-Draft draft-pidlisnyi-aps](https://datatracker.ietf.org/doc/draft-pidlisnyi-aps/): Agent Passport System (APS): Verifiable Authority, Lifecycle, Enforcement, and Evidence for AI Agents. This document specifies the Agent Passport System (APS), a protocol for representing and evaluating authority exercised by AI agents.
