Agent identity

Bring your own agent identity, or use an agent passport

APS needs to know which key an agent signs with. It works with an identifier you already use, and it can create a passport for an agent that has none.

Bring your own identity

The delegation record names its issuer and its subject as identifier strings, and the verifier gets the keys through a resolver that you supply. The record format does not limit which identifier scheme you use.

SDK 8.0.1 ships helpers for did:key and did:web. It also has helpers that carry a SPIFFE identity or an OAuth token into APS after you verified it yourself. Those helpers map fields and check no signature.

Or use an agent passport

An agent passport is a signed record that identifies an agent by its public key. The SDK can create one for an agent that has no identity yet, and an issuer can countersign it.

Anyone who has the record and the public key can check the signature. A valid signature shows that the holder of the private key signed the record and that the record was not changed. It does not show who owns the agent or what the agent may do.

Identity is the first of three questions

Which agent is this?

An identifier and its key answer this. You can use an identifier you already have or create an agent passport that contains the public key of the agent.

Who does it act for?

A principal binding names the person or organization that authorizes the agent. The verifier decides whether it trusts the signer of that binding.

What may it do?

A delegation gives the agent specific authority, for example to read a document, use a tool or spend within a limit. An agent can pass authority to another agent, and the new delegation cannot grant more than the one before it.

A valid signature is not permission

A passport can carry a valid signature while no trusted principal binding and no active delegation exist for it. The protocol defines a separate check for each of these records. A gateway can then use the checked authority to decide whether an action may go ahead.

What the published SDK covers

SDK 8.0.1 exports the passport functions createPassport, verifyPassport and countersignPassport. The newer PassportV2 and PrincipalBindingV1 records of draft -04 are implemented in the SDK source, and the published package does not export them. The identity reference lists what 8.0.1 exports for each identifier scheme.

What APS is

AI agents act for people and companies, but the systems around them often cannot show who authorized an action and what the agent was allowed to do.

The Agent Passport System is an Apache 2.0 open protocol that gives an agent a verifiable identity, ties it to the person or company it acts for, and checks the scope, budget and conditions of its authority before it acts.

Every action that goes through the gateway gets a signed decision, whether it is permitted or denied.

A receipt shows what was decided and under whose permission. It does not by itself show that the action succeeded outside the gateway.
