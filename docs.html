API Reference

AEOESS Gateway v0.4.0

Getting Started

Base URL: https://gateway.aeoess.com/api/v1
Authentication: Bearer token in Authorization header
Get your API key: portal.html
All responses: JSON (Content-Type: application/json) 
# Every authenticated request looks like this:
curl -H "Authorization: Bearer aps_live_..." \
  https://gateway.aeoess.com/api/v1/dashboard

Authentication

POST /signup

Create a new tenant account. Returns an API key. No authentication required.

FieldTypeDescription
namestringrequiredOrganization name
emailstringrequiredContact email (unique)
curl -X POST https://gateway.aeoess.com/api/v1/signup \
  -H "Content-Type: application/json" \
  -d '{"name":"Acme AI","email":"ops@acme.com"}'

# Response:
{ "message": "Account created. Save your API key.",
  "tenant_id": "abc-123",
  "plan": "free",
  "api_key": "aps_live_..." }

GET /account

Account info, current usage, and plan limits.

curl -H "Authorization: Bearer $KEY" \
  https://gateway.aeoess.com/api/v1/account

# Response includes: name, email, plan, usage { agents, delegations, evaluations_this_month, receipts }, limits

Agents

POST /agents

Register an agent. The agent must be registered before it can be evaluated or receive delegations.

FieldTypeDescription
agent_idstringrequiredUnique agent identifier
public_keystringrequiredEd25519 public key (64-char hex)
namestringoptionalHuman-readable name
didstringoptionalDID (did:key:..., did:web:...)
agent_typestringoptionalgeneral | explorer | planner | executor | reviewer | monitor
curl -X POST https://gateway.aeoess.com/api/v1/agents \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"my-agent","name":"Research Agent","public_key":"a1b2c3..."}'

GET /agents

List all agents. Supports pagination: ?limit=20&offset=0&sort=created_at:desc

POST /agents/:agentId/posture

Update agent posture. Restricted agents are denied specific scopes. Suspended agents are denied all actions.

FieldTypeDescription
statusstringrequiredactive | restricted | suspended
reasonstringrequiredReason for posture change
restricted_scopesstring[]optionalScopes to block (for restricted status)

Delegations

POST /delegations

Create a delegation granting an agent scoped authority. The child agent must already exist.

FieldTypeDescription
parent_agent_idstringrequiredDelegating agent (or "_root" for principal)
child_agent_idstringrequiredReceiving agent (must exist in your tenant)
scopestring | string[]requiredComma-separated or array of scopes
spend_limitnumberoptionalBudget cap for this delegation
max_depthnumberoptionalSub-delegation depth (default: 3)
curl -X POST https://gateway.aeoess.com/api/v1/delegations \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"parent_agent_id":"_root","child_agent_id":"my-agent","scope":"data:read,tool:web_search","spend_limit":100}'

GET /delegations

List delegations. Supports pagination.

Evaluations

POST /evaluate

The core enforcement endpoint. Checks if an agent is permitted to perform an action. This is the billable unit.

FieldTypeDescription
agent_idstringrequiredAgent requesting the action
action_typestringrequiredWhat the agent wants to do (e.g. tool:web_search)
scope_requiredstringrequiredRequired scope for this action
action_argsobjectoptionalArguments for pattern-based scope matching (path, target)
estimated_costnumberoptionalEstimated cost (checked against spend limit)
curl -X POST https://gateway.aeoess.com/api/v1/evaluate \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"my-agent","action_type":"tool:web_search","scope_required":"tool:web_search"}'

# Response:
{ "evaluation_id": "...",
  "verdict": "permit",
  "reason": "Permitted: scope \"tool:web_search\" authorized",
  "duration_ms": 1,
  "agent_id": "my-agent",
  "action": { "type": "tool:web_search", ... } }

GET /audit

Evaluation history with filters.

ParamTypeDescription
agent_idstringFilter by agent
verdictstringpermit | deny
action_typestringFilter by action type
fromstringISO 8601 start date
tostringISO 8601 end date
limitnumberPage size (max 100, default 20)
offsetnumberPagination offset

Trust

GET /trust/:agentId/profile

Per-task-class trust breakdown. Shows overall trust score and per-category (data, commerce, tool) scores. Supports temporal windowing.

ParamTypeDescription
window_daysnumberOnly include evaluations from the last N days
curl -H "Authorization: Bearer $KEY" \
  "https://gateway.aeoess.com/api/v1/trust/my-agent/profile?window_days=30"

# Response:
{ "agent_id": "my-agent",
  "window_days": 30,
  "overall": { "evaluations": 150, "permits": 142, "denials": 8, "trust_score": 0.94 },
  "by_task_class": {
    "data": { "evaluations": 80, "permits": 79, "denials": 1, "trust_score": 0.98 },
    "tool": { "evaluations": 50, "permits": 48, "denials": 2, "trust_score": 0.96 }
  } }

GET /public/trust/:agentId

Public trust profile. No authentication required. Returns grade, trust level, DID binding, activity stats, and per-task-class breakdown.

# No auth needed:
curl https://gateway.aeoess.com/api/v1/public/trust/my-agent

Wallets

POST /wallets/provision

Provision a Nano wallet for an agent. Requires active delegation with commerce scope. 4-gate Sybil protection.

FieldTypeDescription
agent_idstringrequiredAgent to provision wallet for

POST /wallets/send

Send Nano payment. 3-gate enforcement: active wallet, commerce scope, spend limit. Atomic debit-before-send.

FieldTypeDescription
from_agent_idstringrequiredSending agent
to_addressstringrequiredNano destination address
amount_xnonumberrequiredAmount in XNO

GET /wallets/dashboard

Wallet overview: active wallets, total balance, frozen count.

Governance Export

GET /governance/export

Full signed governance evidence package. 9 sections: evaluations, receipts, agents, delegations, revocations, alerts, data attribution, settlements, receipt seals. Gateway-signed for third-party verification.

ParamTypeDescription
formatstringjson (default) or csv
sincestringISO 8601 start date
untilstringISO 8601 end date
agent_idstringFilter by agent
# JSON (signed):
curl -H "Authorization: Bearer $KEY" \
  "https://gateway.aeoess.com/api/v1/governance/export"

# CSV (4-table flat format):
curl -H "Authorization: Bearer $KEY" \
  "https://gateway.aeoess.com/api/v1/governance/export?format=csv" \
  -o governance.csv

Billing

POST /billing/checkout

Create a Stripe checkout session for plan upgrade.

FieldTypeDescription
planstringrequiredpro | enterprise
curl -X POST https://gateway.aeoess.com/api/v1/billing/checkout \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"plan":"pro"}'

# Response: { "url": "https://checkout.stripe.com/..." }
