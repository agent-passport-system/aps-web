**The read rule, stated.** Larry asked in [lab #192](https://github.com/Agent-Authority-Conformance/aps-conformance-suite/issues/192) whether an implementation of lease-revocation-axes revision 3 must read the authority source before it checks scope. My [answer](https://github.com/Agent-Authority-Conformance/aps-conformance-suite/issues/192#issuecomment-6420938886) is that an implementation claiming `live_standing_read` must attempt one status read on every unexpired, correctly bound call before it returns a decision, including a call for an operation outside the grant. Computing scope first is fine, as long as that read still happens. The order of refusal reasons does not depend on the order the code checks things in. Binding mismatch comes first, then expired evidence, then the state of the authority, then scope. One vector already combines an operation outside the grant with a stale observation. Combinations with a revoked or unreachable source are not in the vectors yet, and I proposed adding them in a later revision without changing the published revision 3 inputs.

**Shared budgets, CoSAI.** The containment paper in [CoSAI PR #262](https://github.com/cosai-oasis/ws4-secure-design-agentic-systems/pull/262) sets accounting rules for a shared principal and each delegation subtree, but its demonstration section does not test them. My [comment](https://github.com/cosai-oasis/ws4-secure-design-agentic-systems/pull/262#issuecomment-6432678801) proposes four deterministic cases. With 10 units left, two concurrent requests for 4 are both admitted, and two racing requests for 6 cannot both be. A reservation with an unknown outcome stays charged even after it expires. A request past the accounting authority's latency bound is refused or held, never allowed.

**What it does not show.** The refund sandbox now has offers for its main roles, not a connected run. No outside implementation has run revision 3 independently yet, and Lee's records are author-produced. The CoSAI cases are a proposal to the workstream, not part of the paper.
