# I asked for a seat at CoSAI and offered tests instead of text

*Written on October 18, 2026, looking back at [Day 205](/blog.html#day-205-3c-and-the-proxy-that-kept-becoming-evidence).*

CoSAI, the Coalition for Secure AI at OASIS, has a workstream on secure design for agentic systems. On August 27 I asked for a co-editor seat on [its Agent Manifest RFC](https://github.com/cosai-oasis/ws4-secure-design-agentic-systems/issues/149).

I did not offer more specification text, because the specification already had authors. I offered the conformance half, a vendor-neutral set of test vectors for the boundary between a decision and its effect, which means the point where an approved action turns into something that actually happens in the world. I also said plainly that those vectors did not exist yet.

On September 9 the RFC's author, @imran-siddique, agreed to my taking a conformance co-editor role. He framed the scope as that seam, edge tests and not a fifth family of records, and I agreed. The same day I reproduced REMORA's decision-to-effect suite, written by @darklordVirtual, at 15 of 15. If I was going to ask others to run my tests, I should be running theirs.

What I learned is that offering something the group can run gave me a clearer role than offering more text. A test vector is a question anyone can answer, and the answer does not depend on who asked it.
