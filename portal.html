Quick start

1

Register an agent

curl -X POST https://gateway.aeoess.com/api/v1/agents \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"my-agent","name":"My First Agent","public_key":"..."}'
2

Create a delegation

curl -X POST https://gateway.aeoess.com/api/v1/delegations \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"parent_agent_id":"_root","child_agent_id":"my-agent","scope":"data:read,tool:web_search","spend_limit":100}'
3

Run an evaluation

curl -X POST https://gateway.aeoess.com/api/v1/evaluate \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent_id":"my-agent","action_type":"tool:web_search","scope_required":"tool:web_search"}'

Response includes verdict, evaluation_id, and a signed receipt in the audit trail.
