Comparison

Keep your agent framework and add authority you can check

Agent frameworks such as LangChain, AutoGen and CrewAI run the agent. APS describes the authority a verifier can check when an agent asks a system to act.

Where APS fits

LayerWhat it is responsible for
Agent frameworkRuns the agent and coordinates its work
Identity providerSupplies identities and authentication
APS authority recordsDescribe delegated permissions so that a verifier can check them
Enforcement boundaryChecks permission before a request reaches a protected resource
Signed evidenceRecords the decision so that it can be checked later

These layers work together. APS does not replace a framework, an identity provider or the security controls of the resource.

The difference in one example

A person authorizes an agent to buy supplies for up to $200. The framework decides how the agent completes the task. APS records the $200 limit in a signed delegation, and a verifier can check it. An enforcement boundary that sits in front of the payment can refuse a $250 request before it is sent.

That protects only the purchase path where the boundary is in place. An agent with another route to the payment system is not checked.

What APS is

AI agents act for people and companies, but the systems around them often cannot show who authorized an action and what the agent was allowed to do.

The Agent Passport System is an Apache 2.0 open protocol that gives an agent a verifiable identity, ties it to the person or company it acts for, and checks the scope, budget and conditions of its authority before it acts.

Every action that goes through the gateway gets a signed decision, whether it is permitted or denied.

A receipt shows what was decided and under whose permission. It does not by itself show that the action succeeded outside the gateway.
