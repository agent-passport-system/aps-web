The Agent Governance Working Group builds interoperability standards for the agent economy. Multiple projects. Shared primitives. No single vendor controls the specs. If you're building agent infrastructure, the door is open.

Ratified Specifications

Ratified

QSP-1: Encrypted Agent Transport

Defines how agents communicate securely across trust boundaries. Ed25519 to X25519 key conversion, XChaCha20-Poly1305 encryption, forward secrecy. Compatible with qntm relay protocol.

v1.0 · March 2026
Ratified

DID Resolution

Where is this agent's identity document? Resolves did:aps, did:key, and did:web methods to DID Documents. The base layer for identity interop across agent frameworks.

v1.0 · March 2026
Ratified

Entity Verification

Is this agent who they claim to be? Conformance checks for passport validity, delegation chain integrity, and principal linkage. 21-invariant test suite included.

v1.0 · March 2026
Draft

Execution Attestation

Did this agent actually do what it claims? Signed execution proofs with gateway countersignatures. Prevents agents from fabricating action history.

v0.1 · March 2026
