# Security Policy

This repository is the source of agent-passport.org. Security issues here are issues in the site itself, its build, or the data files it publishes.

Report privately: https://github.com/agent-passport-system/aps-web/security/advisories, or security@aeoess.com.

The site publishes a machine-readable policy at https://agent-passport.org/.well-known/security.txt (RFC 9116). Security issues in the Agent Passport System SDKs are reported to the SDK repositories; the TypeScript SDK policy at https://github.com/aeoess/agent-passport-system/blob/main/SECURITY.md is the reference.

Disclosure is coordinated: a fix lands before a report is published.
